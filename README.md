A Clean, ad-free, and offline puzzle experience made using Jetpack Compose.

Features:
- Classic 9x9 gameplay
- [ ] Win cheers
- [ ] Customize Game board size and position
- [ ] Background Score?

#### Architecture:
Sudoku is based on MVVM architecture and demonstrates modern Android development with Jetpack Compose, Hilt, Material3, Coroutines, Flow, RoomDB, and ViewModel.
